司法書士 肢トレ - PWA試作 v001

内容
- index.html: スマホ用学習画面
- manifest.webmanifest: ホーム画面追加用設定
- sw.js: オフラインキャッシュ
- CSV: 令和8年度午後の肢別マスター（v002）

現状
- 不登法・商登法を冒頭で選択
- 年度選択
- 1画面1肢
- 「答えを見る」で出題当時の正誤を表示
- 前へ・次へ
- ランダム出題
- お気に入り
- お気に入りのみ出題
- 進捗・お気に入りは端末内(localStorage)に保存

重要な注意
1. このCSVの正誤は公式解答の組合せから機械的に展開したものです。各肢の法的根拠・現行法との照合は未完了です。
2. これは試作です。実際のスマホでホーム画面追加・オフライン動作を確認するには、HTTPSでホスティングしてください。
3. index.htmlをPCで直接開く(file://)だけではCSV読込やPWA機能が正常に動作しない場合があります。
4. 問題文の利用・複製・外部サービスへのアップロードは、入手元の利用条件と著作権を確認してください。公開・配布はしない前提の個人用試作です。
5. 「進捗」は閲覧済みの記録であり、正解・不正解の記録ではありません。

起動テスト
- HTTPS対応の静的ホスティングにフォルダ内の全ファイルを配置
- 発行されたURLをAndroid Chromeで開く
- Chromeメニューから「アプリをインストール」または「ホーム画面に追加」
- 初回読み込み後に通信を切り、再起動して動作確認
